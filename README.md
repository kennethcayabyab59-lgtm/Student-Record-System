Project Title
Student Record System

Description
Student Record System is a basic computerized system used to store and manage student information. The system allows the teacher/Instructor to add, update, view, and delete student records such as student name, block, course, and grades.
The purpose of the system is to make student record management faster, organized, and easier. It also helps reduce errors and makes searching student information more convenient.

Detailed System Flow
1.Loginh
-Professor/Instructor enters username and password. 
2. Dashboard
-System opens the main dashboard. 
3. Manage Student Records
-Add student 
-Edit student information 
-Delete student record 
-View student list 
4. Save Data
-System stores data in the database. 
5. Logout
-User exits the system securely
